PERSONAL USE / LOCAL WORKFLOW

个人工具。
数据处理在本机。

1014s06 Personal Tool 用于在维护者自己的电脑上完成 Google OAuth 授权，并运行访问本人 Google 数据的 API 脚本。不向公众提供注册或代管账号服务。

01 / 工作方式

授权与运行都由本人控制

  1. 1

    在 Google 页面授权

    浏览器前往 Google 官方授权页面，由本人选择账号、查看请求的权限并决定是否同意。

  2. 2

    在本机保存凭据

    授权脚本把 OAuth 凭据保存到本机文件，供本机脚本使用。凭据不应放入公开仓库或网页。

  3. 3

    按需调用 Google API

    本机脚本向 Google 发起请求，并在本机处理返回数据。此静态说明页不调用 Google API。

02 / 当前权限配置

了解授权的范围，而不只看工具名称

当前 OAuth 配置包含下列服务的较广权限。下表描述权限可能允许的访问，不表示每次运行都会读取或修改全部数据。实际功能应只使用完成任务所需的权限。

当前 Google OAuth 权限所涉及的服务和数据
服务权限涉及的数据与操作
Gmail邮件与邮箱数据，包括读取、发送、修改及删除邮件等操作。当前包含全邮箱权限。
Google Drive云端硬盘文件，包括读取、创建、修改及删除本人授权可访问的文件。
Google Calendar日历及日程数据，包括读取、创建、修改及删除等管理操作。
YouTube本人 YouTube 账号相关数据及管理操作，具体以 Google 授权说明和调用的 API 为准。
Docs · Sheets · Forms文档、电子表格和表单的读取与管理；实际可执行操作由各 API 和获准权限决定。

仅启用某个 Cloud API 不等于已获准访问用户数据；OAuth 权限也不意味着工具可以绕过账号、文件或服务的访问限制。

03 / 联系与控制

可以随时停止使用并撤销授权

通过 Google 账号的第三方连接管理页面撤销访问权限；本机已保存的文件、日志和备份需另行检查和删除。
